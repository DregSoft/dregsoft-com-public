Console Converter

Testing · Not yet publicly available

Converts show files between Yamaha RIVAGE PM, Yamaha DM7 and DiGiCo Quantum3 and Quantum2 consoles.

In
Show file from Yamaha RIVAGE PM, Yamaha DM7 or DiGiCo Quantum3 or Quantum2 console
Out
Show file for another of those consoles

Supported consoles

  • Yamaha RIVAGE PM
  • Yamaha DM7
  • DiGiCo Quantum3 and Quantum2

How it works

  • It writes the source show's mix state into a blank template from the target console.
  • It runs as a web app and a desktop app.
  • Everything runs entirely on your own computer, so show files are never uploaded.
Runs as
Web app, desktop app
Privacy
Runs locally — show files are never uploaded
