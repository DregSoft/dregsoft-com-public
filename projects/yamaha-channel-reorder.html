Yamaha Channel Reorder

Testing · Not yet publicly available

Reorders channels and mixes in Yamaha RIVAGE PM and DM7 show files.

In
Yamaha RIVAGE PM or DM7 show file
Out
Show file with channels and mixes reordered

Features

  • Drag rows (or use Alt+↑/↓) to reorder.
  • Stereo pairs move together.
  • Delete channels, resetting them to defaults and moving them to the end.
  • The original file is never modified.

Where it runs

  • It runs as a web app and a desktop app.
  • Everything runs entirely on your own computer, so show files are never uploaded.
