MQConduit

Not yet publicly available

A desktop app for macOS and Windows that turns OSC messages, MQTT messages and HTTP requests into actions on a computer.

What it can do

  • Launch, hide or quit apps
  • Send keystrokes
  • Type text
  • Wake or unlock a machine

How it works

  • Messages can be sent straight to a computer or routed through an MQTT broker, with the hostname as the topic, so one control surface can drive many machines.
  • It can run a bundled local Mosquitto broker.
  • The OSC and HTTP interfaces support password-protected, signed requests.
